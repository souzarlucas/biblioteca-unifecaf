# 📚 Biblioteca Digital UniFECAF

> Projeto acadêmico desenvolvido para a disciplina de **Design Web** do curso de graduação da **UniFECAF**.

---

## 🎯 Sobre o Projeto

Desenvolvimento da primeira versão da interface web da **Biblioteca Digital UniFECAF**, transformando o protótipo de baixa fidelidade em uma interface funcional, moderna, responsiva e alinhada à identidade visual institucional.

- **Status:** Concluído ✅
- **Demonstração Online (GitHub Pages):** [Acessar Biblioteca Digital](https://souzarlucas.github.io/biblioteca-unifecaf/)

---

## 🚀 Tecnologias Utilizadas

- **HTML5 Semântico:** Estruturação orientada a padrões W3C (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<figure>`, `<footer>`, `<form>`).
- **CSS3 Moderno:** 
  - Layout responsivo baseado em **CSS Grid** e **Flexbox**.
  - Variáveis globais de estilização (`:root`) com a paleta oficial da UniFECAF.
  - Princípios de **Acessibilidade Web (WCAG)** com foco visível (`:focus-visible`) e alto contraste.
  - Efeitos de transição suave e estados interativos (hover/active).

## 🏛️ Seções da Interface

1. **Cabeçalho Fixo (Header):** Logotipo institucional e menu de navegação responsivo.
2. **Hero Banner:** Mensagem de boas-vindas com chamada de ação rápida (CTAs).
3. **Sobre a Biblioteca:** Apresentação institucional e 4 cards com diferenciais do acervo digital.
4. **Banner Intermediário:** Faixa de destaque motivacional para incentivo à leitura.
5. **Nossos Livros (Acervo em Destaque):** Grid responsivo com 6 obras acadêmicas, capas, autores e botão de leitura.
6. **Dica da Semana (Aside):** Informações de apoio e orientações de pesquisa bibliográfica.
7. **As Unidades:** Apresentação com fotos e detalhes do Campus Taboão da Serra (Sede), Polos EAD e Campus Tecnológico.
8. **Atendimento e Contato:** Canais institucionais (endereço, e-mail, WhatsApp) e formulário interativo de contato.
9. **Rodapé (Footer):** Informações de direitos autorais e links de acesso rápido.

---

## 📱 Responsividade

O projeto adapta-se dinamicamente a diferentes resoluções:
- **Desktop:** Layout completo em multi-colunas.
- **Tablet (≤ 900px):** Reorganização dos grids em 2 colunas.
- **Smartphone (≤ 768px):** Menu vertical, colunas empilhadas e botões em largura total para melhor usabilidade touch.

## 💻 Como Executar Localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/souzarlucas/biblioteca-unifecaf.git
   ```
2. Acesse a pasta do projeto:
   ```bash
   cd biblioteca-unifecaf
   ```
3. Abra o arquivo `index.html` em qualquer navegador web moderno:
   ```bash
   open index.html
   ```
